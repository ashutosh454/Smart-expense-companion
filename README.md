# Smart Expense Companion

Smart Expense Companion is an intelligent personal finance tracking web application built with React, Vite, and Tailwind CSS. It helps you manage your income, track your expenses, and view insights into your financial health.

## Features

- **Dashboard**: A comprehensive overview of your total balance, income, and expenses with beautiful charts.
- **Transaction Tracking**: Add, view, and categorize income and expenses effortlessly.
- **Visual Analytics**: Interactive pie charts and bar graphs (powered by Recharts) to visualize your financial data over time.
- **Smart Predictions**: Forecast future expenses and income based on your transaction history.
- **AI Assistant**: A built-in assistant to help you understand your spending habits and provide financial advice.

## Tech Stack

- **Frontend Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui (Radix UI)
- **Routing**: React Router
- **Charts**: Recharts
- **Icons**: Lucide React

## Getting Started

### Prerequisites

Make sure you have Node.js (v18 or higher) and npm installed on your machine.

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/ashutosh454/Smart-expense-companion.git
   ```

2. Navigate to the project directory:
   ```sh
   cd Smart-expense-companion
   ```

3. Install the dependencies:
   ```sh
   npm install
   ```

4. Start the development server:
   ```sh
   npm run dev
   ```

The application will be available at `http://localhost:5173` (or the port specified by Vite).
